# ComfyWorkflowStudio V1.0.0 封版说明

封版日期：2026-09-19

## 版本定位

V1.0.0 是 ComfyWorkflowStudio 的第一版正式功能基线。自本版本起，当前功能范围进入封版状态；后续新增功能、较大交互调整和架构演进统一进入 V2，不再继续扩大 V1 的功能边界。

## V1 核心能力

- 本地优先的 ComfyUI 工作流知识库、依赖检查、Readiness 与 Runtime Preflight。
- Certified Production Run、串行任务、输出管理、素材管理与作品库。
- 漫画页面导入、预览、语义理解、GPT Director 故事改编与 Shot/Episode 生成。
- WebMCP 将真实漫画页交给“童语工坊 · AI动画编剧导演”，并自动接收 Story / Shots / Prompts。
- ChatGPT Web Image Worker 通过本地 Chrome CDP 生成关键帧并回填 Studio，无需 OpenAI API Key。
- 成片工作台支持镜头级工作流选择、关键帧预览、视频生成准备、批量生产入口与生成状态。
- 任务队列与生成记录统一为任务中心。
- 童语作品库支持真实图片/视频预览、筛选与分页。
- 系统设置中心具备 ComfyUI、存储、任务策略、工作流与高级设置能力。
- Windows 启动/关闭脚本与桌面 Python Launcher，可快捷启动工作台、打开浏览器入口并查看服务状态。

## 封版规则

1. V1.0.0 作为第一版固定基线保存。
2. V1 只接受阻断使用的缺陷修复、安全修复和数据兼容修复。
3. 新功能、UI 大改、新工作流体系和新生产链路统一进入 V2。
4. V2 开发不得破坏 V1 的可恢复基线。
5. 发布前的完整自动化回归结果应单独记录；本封版提交本身不等同于一次新的完整回归执行。

## 版本入口

- 固定版本号：1.0.0
- 封版分支：release/v1.0.0
- 后续开发建议：从 release/v1.0.0 创建 V2 开发分支。
