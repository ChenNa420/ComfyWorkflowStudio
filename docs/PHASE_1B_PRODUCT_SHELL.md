# Phase 1B Product Shell

## 目标

按照产品基准 UI 补齐统一创作中心的一级页面和关键详情页。UI 同时承载“童语工坊”业务创作入口与“Comfy 工作流”能力中心，但后端职责继续解耦。

## 童语工坊页面

- 首页
- 故事创作
- 角色管理
- 分镜设计
- 成片工作台
- 作品库
- 发布管理

## Comfy 工作流页面

- 工作流库
- 工作流详情
- 导入工作流
- 工作流适配向导
- 创建任务
- 任务队列
- 生成记录
- 作品库
- 素材管理
- 模型与节点
- 系统设置

## 成片工作台生产阶段

1. 故事创作
2. 分镜设计
3. 首帧生成
4. 视频生成
5. 字幕配音
6. 成片输出

工作流选择采用三级覆盖：`SHOT > EPISODE > SYSTEM`。

## Phase 1C / 1D 接口预留

- 批量导入 ZIP / 多 JSON
- UI Workflow (`nodes + links`) 分析
- 输入用途识别与人工确认
- Manifest 生成与编辑
- 模型 / Custom Node 依赖检查
- Runtime Clone
- ComfyUI `/prompt` 提交与 `/history` 确认
- 结果回收、作品落库
